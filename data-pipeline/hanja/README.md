# 한자 성명학 데이터 (hanja.json)

부모가 입력한 이름 한자의 **원획(성명학 획수)**·**자원오행**을 조회하기 위한 데이터.

## 생성
```
python3 data-pipeline/hanja/build_hanja.py   # → hanja.json (약 8,500자)
```

## 출처 (모두 공개·자유이용)
- **획수·부수**: Unicode Unihan (kRSUnicode, kTotalStrokes) — Unicode License
- **부수원획 214**: Unihan에서 자동 도출 (강희부수 U+2F00~ → 정자체 → 획수)
- **원획 계산**: `원획 = 부수원획[R] + 나머지획수` (성명학 표준, 검증 19/19)
- **자원오행**: `build_hanja.py`의 부수→오행 매핑 (전통 부수 계열, **유파차 있음 = 참고용**)
- **특수획수**: STROKE_EXCEPTIONS (成=7 등 전통 예외)
- **훈(뜻)**: LLM 일괄 변환. 같은 음의 후보가 수십 개라(예: "준" 43자) 훈이 없으면 부모가 고를 수 없다.
  세 번에 걸쳐 채웠고 **7,820자(91.7%)** 확보:
  1. 2026-08-29 — Unihan `kDefinition`(영어)을 한국 전통 훈으로 옮김 → 7,527자
  2. 2026-09-16 — 영어 정의 없이 글자만 주고 재시도(Sonnet) → +75자
  3. 2026-09-16 — 같은 방식으로 더 강한 모델 재시도(Opus) → +156자. 玉 부수 계열
     (옥이름·옥돌·옥빛)이 대량 확보됐는데, 이름에 자주 쓰이는 부류라 체감이 크다.
  4. 2026-09-16 — 부수 힌트를 더해 흔한 이름 음절만 재시도(Opus) → +18자. **여기서 고갈.**
  5. 2026-09-16 — **한국어 위키낱말사전 API** → +43자. LLM이 세 번 다 몰랐던
     한국 고유 이두자(乻 땅이름 얼 · 乷 땅이름 살 · 亐 땅이름 울)가 여기서 나왔다.
     `{{한자풀이|훈=…|음=…}}` 형식을 파싱하고, 표기 규칙(공백 제거·관형형·5자 이내)에
     맞추는 것만 LLM에 맡겼다 — **뜻을 만들지 않고 형식만 바꿨다.**
     출처: 한국어 위키낱말사전 (CC BY-SA 4.0), https://ko.wiktionary.org
     ※ 위키 API는 제목을 NFC 정규화한다 — 호환한자(U+F900~)를 조회하면 표준형으로
       바뀌어 돌아오므로, 응답의 `title`을 그대로 키로 쓰면 엉뚱한 글자에 값이 붙는다.
  남은 **705자**는 `乧 乷 乻 亐 剆` 같은 희귀자·한국 고유 이두자로 모델도 뜻을 모른다.
  **지어내게 하지 않고 비운 채 둔다** — 아이 이름에 틀린 뜻이 붙는 것이 후보에서
  빠지는 것보다 나쁘다. 폼에서는 "뜻 미상 한자 더 보기"로 펼쳐 눈으로 골라 쓸 수 있다.

## 형식
`{ "福": {"strokes":14,"radical":113,"element":"金","sound":"복","hun":"복"}, ... }`
※ `hun`은 없을 수 있다(선택 필드). 없으면 화면에서 생략한다.

## 주의
- 자원오행은 부수 계열 기반 v1 (참고). 더 권위 있는 표 확보 시 매핑 교체.
- 수리사격(획수 길흉) 판정은 낙인·개명 리스크로 **미구현** (자원오행 보완만).
- 훈은 영어 정의를 옮긴 것이라 관용 훈음과 다를 수 있다. 이름에 흔한 음절
  (준·서·현·민·지·우·연·윤·하)은 육안 검수했고, 이상한 값을 발견하면 hanja.json에서 직접 고친다.
- 후보에 **인명용 한자가 아닌 글자가 섞여 있다**(Unihan 전체 기준). 대법원 인명용한자표로
  거르면 후보가 줄고 출생신고에 못 쓰는 한자를 배제할 수 있다 — **미적용**.
  ⚠️ 법제처가 제공하는 「인명용추가한자표」 별표는 HWPX인데, **한자가 전부 이미지(BMP 7,274장)**로
  박혀 있어 텍스트 추출이 불가능하다(2026-09-16 확인: 텍스트 노드 7,109개 중 한자는 15자뿐).
  적용하려면 OCR이 필요하고, 잘못 읽으면 없느니만 못하다.
